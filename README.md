# AI-Based Malaria Diagnosis Support System

Team project for CS 414 (AI and Intelligent Systems).

## Setup
1. Install Python 3.14.10 and Git.
2. git clone https://github.com/TatendaAngels/malaria-symptom-screening-system.git
3. python -m venv .venv
4. .venv\Scripts\activate
5. pip install -r requirements.txt
6. python webapp\app.py

## Folders
- webapp/ : Flask app, templates, static files
- model/ : data processing, training, evaluation, prediction
- tests/ : tests
- docs/ : documents
- archive/ : old designs
